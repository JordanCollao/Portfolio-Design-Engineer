The problem

My family owns a property in Lima where several tenants share one electricity meter. Every month someone had to manually calculate each tenant's share, write up the breakdown, and send it on WhatsApp. The math wasn't hard (split by usage, plus the common areas), but doing it every month was tedious and easy to get wrong.

/how it works

How it works

I built a small private app that takes the monthly meter reading and per-tenant consumption, calculates each share with the agreed allocation rules, generates a clear breakdown for each tenant, and sends each one their bill via WhatsApp directly.

The interface has three inputs and one button. The output is a formatted message ready to send. Everything runs locally, so tenant data stays on the family's computer.

Where it is now

My family uses it every month. Bill day went from 30 minutes of math and copy-paste to under 2 minutes, with no errors since we started using it.
